# Contributing

Read [AGENTS.md](AGENTS.md) and [docs/DESIGN.md](docs/DESIGN.md).

1. **Name the consumer.** New types, dimensions or units arrive with a real user, not ahead of it.
2. **Prove it costs nothing.** Static assertions for size and trivial copyability; a paired benchmark
   against plain numbers.
3. **Prove misuse fails.** Concept checks that wrong code does not compile.
4. **Keep it a vocabulary.** No numerical methods, no I/O, no allocation, no product names.
